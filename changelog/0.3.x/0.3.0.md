# 0.3.0 — 2026-11-03

## Added

- Serve `epa-drinking-water-guide` as an MCP skill resource.
- **Profile facilities** resolve SDWIS facility IDs within a PWSID, with exact filtering and facility-type labels ([#19](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/19)).
- **School/daycare discovery** adds `school_or_daycare`; discovery and summary preserve school/daycare and wholesaler source indicators ([#25](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/25)).
- **Enforcement scope** accepts reported-state/county membership for actions; associations and violation-ID filters require PWSID and retain geographic intersections ([#26](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/26)).
- **UCMR scope** accepts service ZIP alone without SDWIS membership requests; supplied system/geographic selectors still intersect ([#24](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/24)).

## Changed

- **Whole-row paging** returns requested available records or describe tables without byte-based cuts; every `limit` defaults to 10 and caps at 500. `SDWIS_CLAMP_LIMITS=true` clamps with a notice, log and counter; false advertises and enforces `maximum:500` ([#18](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/18)).
- **Caller guide delivery** includes the published skill in npm, Docker, MCPB and plugins; contract and configuration documentation covers the expanded research workflows.

## Removed

- **Text recovery** removes `view`/`record_cursor` from all eight paging tools and `record_identity`/`encoding`/`text`/`offset` outputs; dataframe outputs also remove `phase`. Omit legacy inputs, including explicit `view:records`, and consume whole `items` with `cursor`. Source `phase` remains.

## Fixed

- **Literal selectors** accept punctuated action codes, names and counties through safe DMAP pushdown and complete local matching; label dictionaries load by value type to exhaustion ([#17](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/17), [#20](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/20)).
- **Geographic source pages** retain final provenance and whole rows without response-budget failures ([#21](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/21)).
- **SQL errors** preserve known caller-correctable path-redacted diagnostics and structured details with recovery guidance; unknown engine failures remain generic ([#22](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/22)).
- **Describe continuations** survive query-driven table TTL extensions while retaining their original deadline and structural selection checks ([#23](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/23)).
- **Staged membership checkpoints** return membership continuations without allocating empty tables or claiming no matches; resolved empty selections remain stageable ([#27](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/27)).
