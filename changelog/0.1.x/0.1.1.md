# 0.1.1 — 2026-10-25

## Added

- **Six EPA tools** resolve water systems, inspect contact-free profiles, retrieve historical violations and enforcement, select LCR summaries or UCMR 5 measurements, and explain source codes and coverage.
- **Three optional DataCanvas tools** describe, query, and remove staged partitions using caller-held canvas IDs; npm and Docker support DuckDB, while the portable Claude Desktop bundle provides EPA reads with canvas disabled.
- **Provenance and continuation** preserve source nulls, censoring, filters, revision metadata, and conservative completeness across whole-record pages and bounded staging.

## Fixed

- **DMAP composite ordering** specifies ascending directions for each column so paged source reads succeed ([#1](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/1)).
- **SQL retention** honors the configured canvas row ceiling, including the default 10000, up to the server maximum 25000 ([#2](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/2)).
- **EPA timestamps** accept valid non-midnight times, retain the source calendar day, and preserve the original timestamp in a raw field ([#3](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/3)).

## Security

- **Source formatting** preserves literal source strings and field names through CommonMark rendering, renders HTTP(S) values as deliberate links, and accounts for both MCP surfaces when paging ([#4](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/4)).
