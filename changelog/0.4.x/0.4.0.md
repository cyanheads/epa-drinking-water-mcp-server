# 0.4.0 — 2026-11-21

## Added

- **`sdwis_search_water_systems`** accepts `seller_pwsid` to find distinct buyers from EPA facility records of any status. The discovery activity filter applies to the buyer system. ([#29](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/29))
- **Violation and enforcement rows** include EPA descriptions in `compliance_status_label`, `rule_label`, and `originator_label`; unmapped labels remain null. Completed empty selections can identify codes missing from EPA dictionaries and direct UCMR analyte lookups to the UCMR dataset. ([#31](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/31))

## Changed

- **Geographic membership** finds county matches first, confirms reported legal-entity state in batches, and reuses complete memberships across SDWIS and UCMR 5 for up to one hour. Cache hits report the acquisition time; each selection fetches its own fact rows. ([#30](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/30))
- **Breaking — `sdwis_dataframe_query`** rejects result aliases and CTE names that match 35 additional DuckDB metadata view names with `system_catalog_access`. Choose a different alias or CTE name if your query uses one such as `duckdb_columns`.
- **`sdwis_dataframe_describe`** exposes DuckDB's exact column `engineType` when reported and propagates caller cancellation.
- **Bun minimum** rises from 1.4.0 to 1.4.4. Development tooling syncs framework references and validates release tags and MCPB packaging.

## Fixed

- **EPA source tools** return typed recovery guidance for HTTP and exhausted transport failures and release failed response bodies before retrying. ([#32](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/32))
- **Discovery and reference pagination** advertise a restart hint when the source changes during retrieval.
- **MCPB cleanup** preserves framework runtime modules under `dist/ext/skills/`.
