# 0.2.0 — 2026-10-25

## Added

- **Source coverage** exposes retrieval identity and partition positions through `selection_partition`; dataframe describe/query report `selection_coverage`, including required UCMR companions and immutable query snapshots ([#10](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/10)).
- **Input schemas and recovery** advertise accepted PWSID, date, ZIP and prefix formats and declare reachable selector/capacity failures with recovery guidance ([#12](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/12)).

## Changed

- **`sdwis_dataframe_describe`** returns one table per item with `columns` instead of `column`; `limit`, `returned`, and `totalCount` count tables. Oversized metadata supports lossless text recovery ([#11](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/11)).
- **Plugin and development tooling** add Agent Plugins 1.0.0 root metadata, refresh framework skills and packaging checks, align setup documentation, and set the dependency release-age guard to one day.

## Fixed

- **Violation date overlap** includes records whose known endpoint proves overlap despite a missing endpoint; notices count examined rows with indeterminate overlap ([#6](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/6)).
- **Lead alias** selects both `1030` and Lead and Copper Rule code `5000`, including copper and monitoring records; explicit codes select themselves ([#7](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/7)).
- **Membership continuations** checkpoint slow SDWIS and UCMR membership work before the deadline and resume from the last committed page ([#8](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/8)).
- **Continuation retention** prunes obsolete UCMR pointers, refreshes validated idle activity, and authenticates SQL positions without growing a pointer map; retained SQL replay survives source-table removal ([#13](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/13)).
- **UCMR timestamp bounds** normalize accepted timestamp selectors to calendar days before filtering and continuation binding ([#14](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/14)).
- **Oversized SQL recovery** removes `follow_up.sql` and instructs callers to reuse their original SQL, keeping long-query errors within the response budget ([#15](https://github.com/cyanheads/epa-drinking-water-mcp-server/issues/15)).
- **Empty upstream bodies** fail `upstream_contract_changed` after one fully read HTTP 200 response instead of retrying.
- **Portable bundles** retain MCP SDK runtime extensions under `dist/ext/skills/` while removing dependency development files and native bindings.
